## V-1. ✅ 背景の幾何学模様パターンが消失し、真っ白な無地に（元 G-2）

### 決定（2026-09-23）

**アプリ面（スマホ幅の内側）は意図的に無地のまま。復活させない。**
模様付き背景は現在のモバイル UI ではほぼ使われず、可読性・ダークモード・カードの階層表現と
干渉するため。旧 Vue 版の模様は Vuetify 時代の装飾と位置づける。

代わりに「アプリ面」と「その外側（PC 表示時のスマホ幅を超える余白）」を分けて扱う。

### 対応内容

- `(private)/layout.tsx` の shell を `max-w-md`（448px）で中央寄せし、`bg-background` + `sm:border-x` で
  アプリ面の輪郭を出す。header・main・ボトムナビが同じ幅に揃う。
- `body` の地を `bg-muted` にし（[globals.css](../nextjs/src/app/globals.css)）、外側とアプリ面を区別する。
  スマホ幅では shell が全面を覆うので見た目は変わらない。
- 幅の制限は shell 1 箇所に集約。各画面（`*-screen.tsx` / `note/page.tsx`）と
  ボトムナビ（旧 `max-w-screen-sm`）が個別に持っていた `max-w` は削除。
  これで PC 表示時に header の要素が左右端に飛ぶ・ナビの列幅が本文とずれる問題も解消。

### 見送ったもの

- 外側の余白にだけ旧模様を敷く折衷案。アイデンティティを残す手として有効だが、
  スマホ専用アプリで PC 表示の装飾に手をかける理由が薄く、薄グレーの無地を採った。
  欲しくなれば `body` の CSS 1 箇所で足せる。
- 「スマホでご覧ください」ゲート表示・スマホ枠モックアップ表示。PC で確認する開発者/レビュアーを
  締め出す、または保守コストに見合わないため。

## V-3. 🟡 bank 残高推移グラフの見た目差（凡例・軸の性質・アスペクト比）（元 J-2）

### 現状

| 観点 | 旧Vue版 (Chart.js) | Next版 (Recharts) |
| :--- | :--- | :--- |
| 凡例 | **なし** | **常設**（`ChartLegend`） |
| X軸 | `type:'time'` の時間軸（`YYYY/MM`） | カテゴリ軸（`minTickGap`） |
| ツールチップ | `YYYY/MM/DD`（日付書式あり） | `〜万` 単位（**日付書式が失われている**） |
| 高さ | 親高さに追従 | `aspect-video`（16:9 固定） |
| 線/塗り | `tension:0.2`・塗りあり | `type='monotone'`・`fillOpacity=0.3`・`strokeWidth=2` |
| 空データ時 | 空のグラフ枠を残す | `return null` で**グラフごと消える** |

参照: [bank.vue:119-135](../pages/bank.vue) / [bank-balance-chart.tsx](../nextjs/src/features/bank/components/bank-balance-chart.tsx)

### 差の要点

凡例の有無・軸の性質・アスペクト比・ツールチップの日付精度が変わり、残高推移の読み取り感が変化している。

### 判断が必要な論点

- **ツールチップの日付精度の喪失は実用上の後退**の可能性が高く、ここだけは戻す価値があるかもしれない
  （他の項目と違い、質感ではなく**情報量**の減少）。
- 凡例の常設／カテゴリ軸／`aspect-video` は Recharts の素直な使い方でもあるため、
  Vue 版に合わせるか Recharts 流のまま統一するかを決める。
- 空データ時にグラフごと消える挙動は、他画面の空状態表現（`text-muted-foreground` の文言）と
  揃えるかどうかも併せて判断する。
