## V-1. 🔵 背景の幾何学模様パターンが消失し、真っ白な無地に（元 G-2）

### 現状

- **旧Vue版**: `v-main` に `bg-geometric-pattern` を敷き、全画面に固有のテクスチャがあった
  （radial-gradient のドット＋斜め線グリッド。lightsteelblue のドット＋グレー斜線、109px タイル。
  [default.vue:252-276](../layouts/default.vue)）。
- **Next版**: 背景は `--background: oklch(1 0 0)` の**純白・無地**。
  [globals.css](../nextjs/src/app/globals.css) に geometric / pattern 系の記述はない。

### 差の要点

アプリの地の視覚アイデンティティ（模様のある背景）が失われ、のっぺりした白背景になっている。
カード類と背景のコントラストの付き方も変わる。

### 判断が必要な論点

- 元リストの方針では色を対象外としたが、「**模様の有無**」は色ではなく質感・情報設計の話なので
  方針の射程外。復活させるか、白無地のままモダンな見た目を採るかを決める必要がある。
- 復活させる場合、カード/ダイアログの影やボーダーの設計を背景の模様に合わせて見直すかも併せて判断する。

### 対応方針メモ

復活させるなら `body` に同等の CSS グラデーション背景を **1 箇所足すだけで全画面に効く**（実装コストは小）。
判断さえ付けば着手は容易。

## V-2. 🟡 bank 画面に口座管理（設定タブ）が同居している（元 J-1）

### 現状

- **旧Vue版**: bank 画面は「チャート＋履歴＋ボタン＋残高テーブル」の**残高閲覧専用**。
  口座の追加/編集は**設定画面側**にあった（[bank.vue:1-62](../pages/bank.vue)）。
- **Next版**: [bank-screen.tsx](../nextjs/src/features/bank/components/bank-screen.tsx) が
  `<BankSettingTab>`（口座カードグリッド＋追加）を**残高テーブルの下に同居**させている。

### 差の要点

画面構成が「残高専用」→「残高＋口座管理の統合」に変わり、設定から辿る導線が変わって bank 画面が縦に長くなる。

### 現状を採っている理由

`bank-screen.tsx` に「**口座管理（追加/編集）は BankSettingTab を同画面に据えて導線とする**」と
コメントで明記されており、Vue 版に戻さない **意図的な設計判断**として実装されている。

### 判断が必要な論点

- この統合を正式な仕様として確定するか、Vue 版どおり設定画面へ戻すか。
- 統合を維持する場合、画面が縦に長い点を**タブ分け or アコーディオン**で緩和するかを検討する。

## V-3. 🟡 bank 残高推移グラフの見た目差（凡例・軸の性質・アスペクト比）（元 J-2）

### 現状

| 観点 | 旧Vue版 (Chart.js) | Next版 (Recharts) |
| :--- | :--- | :--- |
| 凡例 | **なし** | **常設**（`ChartLegend`） |
| X軸 | `type:'time'` の時間軸（`YYYY/MM`） | カテゴリ軸（`minTickGap`） |
| ツールチップ | `YYYY/MM/DD`（日付書式あり） | `〜万` 単位（**日付書式が失われている**） |
| 高さ | 親高さに追従 | `aspect-video`（16:9 固定） |
| 線/塗り | `tension:0.2`・塗りあり | `type='monotone'`・`fillOpacity=0.3`・`strokeWidth=2` |
| 空データ時 | 空のグラフ枠を残す | `return null` で**グラフごと消える** |

参照: [bank.vue:119-135](../pages/bank.vue) / [bank-balance-chart.tsx](../nextjs/src/features/bank/components/bank-balance-chart.tsx)

### 差の要点

凡例の有無・軸の性質・アスペクト比・ツールチップの日付精度が変わり、残高推移の読み取り感が変化している。

### 判断が必要な論点

- **ツールチップの日付精度の喪失は実用上の後退**の可能性が高く、ここだけは戻す価値があるかもしれない
  （他の項目と違い、質感ではなく**情報量**の減少）。
- 凡例の常設／カテゴリ軸／`aspect-video` は Recharts の素直な使い方でもあるため、
  Vue 版に合わせるか Recharts 流のまま統一するかを決める。
- 空データ時にグラフごと消える挙動は、他画面の空状態表現（`text-muted-foreground` の文言）と
  揃えるかどうかも併せて判断する。
