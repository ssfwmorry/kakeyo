## 文字と形

- 大見出し 30 / Bold。見出し 17 / Semibold。本文 16。補足 13。金額 40〜44 / Bold・等幅数字（`tabular-nums` を body に）。
- 角丸: アイコン面 8 / ボタン 12 / カード 14（設定系リスト・シート内カード）〜16（カレンダー・集計・口座のカード）/ シート 20 / チップ 999。

- マイナス金額は U+2212「−」、プラスは「+」。桁区切りあり。日付の曜日は**全角括弧**「9月25日（金）」。

## ボトムシート（Dialog はすべてこれ）

- 暗幕 `--overlay`。タップで閉じる。
- シート: `bg var(--background)`（**白ではない**）、`border-radius 20px 20px 0 0`、`padding 8px 16px 34px`（下端は `max(34px, env(safe-area-inset-bottom))`）、縦 gap 14（設定系のシートは 12〜14）。
- 先頭にグラバー 36×5 r3 `--grabber` 中央。
- ヘッダー h44、grid `1fr auto 1fr`（または `44px 1fr 44px`）:
  - 左: 36px 丸ボタン `--muted` 地・`--foreground`。× 18px stroke 2.4（`aria-label="閉じる"`）または ‹（戻る）。
  - 中央: タイトル 17/600。必要ならタグ（「共有」h20 px6 r6 `--secondary`/`--primary` 11/700）。
  - 右: 編集時のみ 36px 丸のゴミ箱（`--muted` 地・アイコン `--destructive` 18px、`aria-label="この◯◯を削除"`）。
- 高さの 2 種:
  - **内容高**（設定のシート・予定・TODO・お知らせ・残高登録）: 内容に応じ、最大 790/844（≒ `max-h-[94dvh]`）で内側スクロール。
  - **全高固定**（入力①②・記録の編集・定期の記録の追加/編集）: `top: 56px` から画面下端まで（`h-[calc(100dvh-56px)]`）。テンキー一式を下に張り付け、内容はスクロールしない。
- シート内のフィールド: 白カード r12〜14、行 h48〜52 `padding 0 14px`、ラベル 13px `--muted-foreground` + 入力 16〜17px。行の区切りは `--line-soft`。

  活性は**クライアント状態**で切り替える（Conform の必須エラーを出さない）。

## トースト（Toast.dc.html・T02）

- 上端 `top: calc(env(safe-area-inset-top) + 7px)`、左右 16、シート・暗幕より手前。同時に 1 枚（新しいものが置き換える）。
- 完了 `role=status`: 地 `--foreground`（#16191A）・文字白、左に 22px 丸（`--primary`）+ 白チェック 13px stroke 3、右に × 28px（白 70%・14px stroke 2.6・`aria-label="閉じる"`）。r14、`padding 12px 16px`、影 `0 8px 24px rgba(22,25,26,.28)`、15/600 lh1.4、1〜2 行。約 3 秒で消える。
- エラー `role=alert`: 地 `--destructive`・文字白、左にアラート丸 22px stroke 2.2。自動では消えない（× か次のトーストで消える）。文は理由を先に書き「できません」で終える。
- 文言: 登録しました／変更しました／削除しました／入れ替えました／確認しました。対象名を入れるときはかぎかっこ（「「通院」を削除しました」）。

## 日付・数値の書式（`src/lib/shared/domain/format.ts`）

- `M月D日（曜）`（全角括弧）: 日別見出し・入力②の日付・削除確認の本文。
- `M/D（曜）`: 予定の日付ボタン・リマインダー一覧・お知らせ。今年以外は `Y年` を前置（リマインダー）。
- `YYYY/M/D`: 残高登録の記録日。
- `M月`（h1）+ `YYYY`（年）: カレンダーの月見出し。
- 金額: `toLocaleString('ja-JP')`、符号は「−」「+」。

## サーバ層の扱い（AGENTS.md の要約）

- 取得は既存 services を再利用。書き込みはシートから呼ぶので**遷移せず `FormActionResult.toast` を返す Action** を `src/features/<feature>/actions.ts` に置く（`features/record/actions.ts` / `features/plan-reminder/actions.ts` が先例）。
- `isPair` は編集対象自身の区分から決める（Cookie ではなく）。新規はセッションのモード。
- 再検証は layout 単位（設定は `/setting`、記録は `/`）。
- デモモード（`features/demo`）は取得・更新の両方に射影が要る。新しいクエリ・Action を足したら `features/demo/server/queries/*` にも同名関数を足す。
