- `formatMonthDayWeekJa(date)` → `9月25日（金）`。

- `formatSlashDate(date)` → `2026/9/25`。
- `formatSignedPrice(price, isPay)` → `−2,480` / `+320,000`（U+2212）。
- 既存 `lib/shared/domain/date.ts` の関数を内部で使い、`dayjs` を直 import しない。
