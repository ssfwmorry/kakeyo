## 計算（原典と旧実装が一致している）

- 率は 11 段階。`RATE_LIST = [1, .9, .8, .7, .6, .5, .4, .3, .2, .1, 0]` = **自分が負担すべき割合**。
- グループごとに `sum`（合計）、`asIs`（自分が実際に払った額 = 自分の立替の合計）、`toBe = round(sum * rate)`（自分が負担すべき額）、`diff = toBe - asIs`。
- 全グループの `diff` の合計が**正なら自分が渡す**、負なら受け取る、0 なら精算不要。
