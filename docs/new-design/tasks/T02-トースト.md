# T02 トースト

- 依存: T01。
- 原典: `project/Toast.dc.html`（860×560 の仕様ボード。完了・エラーの 2 種と文言ルール）。`SetPlanTypeSaved` / `SetPlanTypeBlocked` / `NotifyAfter` に画面内での出方がある。

## デザイン仕様
- 位置: 画面上端、ステータスバーの下（`top: calc(env(safe-area-inset-top) + 7px)`）。左右 16 の余白で幅いっぱい（シェル幅 `max-w-md` の内側）。タブバー・キーボードに被らない。**シート・暗幕・ダイアログより手前**。
- 形: r14、`padding 12px 16px`、影 `0 8px 24px rgba(22,25,26,.28)`、flex gap 10、文字 15/600 lh1.4、1〜2 行。
- 完了（`role=status`）: 地 `#16191A`（ライト・ダーク共通で `--foreground` ではなく固定色。ダークは `--card` #1B1F21 相当でよい）、文字白。左に 22px 丸（`--primary`）+ 白チェック 13px stroke 3。右に × 28px（`rgba(255,255,255,.7)`、アイコン 14px stroke 2.6、`margin-right -6px`、`aria-label="閉じる"`）。**約 3 秒**で自動で消える。
- エラー（`role=alert`）: 地 `--destructive`（#C4372B）、文字白。左にアラート丸アイコン 22px stroke 2.2（塗り無し）。× は同じ。**自動では消えない**。× か次のトーストで消える。
- 同時に 1 枚。新しいものが古いものを置き換える。
- 文言: 登録しました／変更しました／削除しました／入れ替えました／確認しました。対象名はかぎかっこ（「「通院」を削除しました」「「電気代の支払い」を確認しました」）。エラーは理由を先に書き「できません」で終える（「紐づくデータがあるので削除できません」「定期の記録から作られた記録は、同じ月の中でだけ変更できます」）。

## 現状
- `src/app/layout.tsx` の sonner `<Toaster position='bottom-center'/>`（`src/components/ui/sonner.tsx`、旧トークン、`.v2-root` の外）。`useFormToast` → `toast[type](message)`。`FlashToast` は redirect 後に同じ経路で出す。sonner 既定は 4 秒・3 枚スタック・× なし。

## やること
1. v2 用 Toaster を `src/v2/components/toaster.tsx` に作り、`src/app/v2/layout.tsx` の `.v2-root` 内に置く（root の Toaster は旧画面用に残す。v2 配下では二重に出ないよう root 側を v2 パスで抑止するか、`Toaster` を v2 layout にだけ置くよう root layout を分岐）。
2. sonner の `toast.custom`（または `unstyled` + `classNames`）でデザインの見た目を描く。`position='top-center'`、`offset` に safe-area、`visibleToasts={1}`、固定 `id`（例 `'v2'`）で置き換え。`duration`: success 3000、error `Infinity`。× ボタンで `toast.dismiss`。
3. `useFormToast`（`src/components/form/use-form-toast.ts`）はそのまま使えるようにする（`toast.success/error` を v2 Toaster が受ける）。v2 からの直接呼び出しは `src/v2/lib/toast.ts` の `showToast({ type, message })` に寄せる。
4. `L.snackbar` に `checked`「確認しました」を追加。対象名入り文言のヘルパ `quoted(name)` → `「name」` を `src/lib/shared/labels` か `src/v2/lib/format.ts` に置く。
5. z-index が Base UI Drawer / AlertDialog より上になることを確認。

## 完了メモ（2026-09-25）
- 実装: `src/v2/components/toaster.tsx`（`V2Toaster`。sonner の Toaster を `unstyled` にし、`classNames` / `icons` で完了（黒）・エラー（赤）の見た目を Toaster 側に定義。`position='top-center'`、`offset`/`mobileOffset` の top に safe-area + 7px、`visibleToasts={1}`、× は sonner の `closeButton` を `order-last` で右端へ）。幅と位置は `<ol>` の inline style で `min(100vw − 32px, 28rem − 32px)` 中央に固定（sonner は 600px 以下で幅 100% に切り替えるため）。
- `src/v2/lib/toast.ts` の `showToast({ type, message })`: 固定 id `'v2'`（新しいものが置き換える）、success/info は 3000ms、error/warning は `Infinity`。文言を `<span role="status|alert">` で包む（sonner の live region は polite 固定のため）。`dismissToast()` も置いた。
- `useFormToast` は presenter を context（`src/components/form/toast-presenter.tsx`）から受ける形にし、既定は sonner の素の呼び出し。`V2Toaster` が `showToast` を provide するので、v2 内の `useFormToast` 呼び出し側（master-sheet / plan-sheet / amount-step / todo-chips / sheet-delete-button）は無改修。
- root layout の Toaster は `LegacyToaster`（`src/features/layout/components/legacy-toaster.tsx`）に置き換え、`/v2` 配下では描画しない（二重表示の防止）。`FlashToast` は root に残したままで、v2 配下では v2 Toaster に流れる（見た目は同じ。ただし error の表示時間だけ Toaster 既定の 3 秒。redirect 先が v2 になる Action はまだ無い）。
- `L.snackbar.checked`「確認しました」を追加。`quoted()` は T01 で `src/v2/lib/format.ts` に実装済みのものをそのまま使う。
- v2 で `toast` を直接呼んでいた `reminder-screen.tsx` を `showToast` に寄せた。
- 色の判断: 完了の地は仕様どおり #16191A 固定。エラーの地も **#C4372B 固定**にした（ダークの `--destructive` #F2685C は白文字とのコントラストが 2.6 で読めないため。完了と同じく「トーストはテーマで地を変えない」で揃える）。
- 確認: デモ（ペアあり）で方法の追加 → 上端に黒トースト、約 3.3 秒で消える（ライト・ダーク）。実データ（develop の test ユーザ）で使用中の予定カテゴリを削除 → 赤トーストがシートの手前に出て 5 秒後も残り、シートを開いたまま × で消える。続けて別のカテゴリで同じ操作 → 1 枚のまま文言が置き換わる。PC 幅 1280 でも 416px 中央・上端 7px。`pnpm check:full` / `pnpm test` 通過。
- 残したもの: sonner の `<li>` 自体には role が付かない（文言側の span で代用）。`/v2/summary` の prefetch 404 はタスク一覧の既知の段差（T12）。
