## デザイン仕様

### 画面の骨格

- 設定配下と同じ `ScreenHeader`（`padding 47px 8px 0` h44、grid `1fr auto 1fr`）。左「‹ 集計」（アクセント 16px）。中央タイトルは**空**。
- 見出し: 12px の色丸 ＋ h1 28/700（`white-space: nowrap`）。名前は「食費 › スーパー」のようにカテゴリ › サブカテゴリ、方法軸なら方法名。
- タグ行（gap 6・`margin-top: -4px`）: h24 `padding 0 10px` r12 `--muted` 地・`--muted-foreground` 12/600。2 枚:
  - 「支出カテゴリ」（軸と支出収入で 4 通り: 支出/収入カテゴリ・支払/受取方法）
  - 「個人 · 立替込み」（モードと立替の扱い。共有なら「共有」1 語）
- 月ナビ行: 前後 36px 丸 ＋ 月ラベル 16/600（**ピッカーは無い**）／ 右端に「合計」12px ＋ 金額 17/700 ＋ 「円」12px。

### 日別グループ

- 見出し行（`padding 0 4px`）: 「9月25日（金）」13/600 `--muted-foreground` ／ 右端に日計 12px `--muted-foreground`（符号付き）。
- 白カード r16。行 h60 `padding 0 14px` gap 12:
  - 36px 淡色タイル r10 ＋ 20px のカテゴリアイコン（**DB にアイコンが無いので D15 と同じく色ドットで代用する**。T04 の記録行と同じ形に揃える）。
  - 本文（`border-top` は 2 行目以降・先頭ブロックの右から）: 1 行目 15px に名前、後ろに**定期アイコン** 13px（`aria-label="定期の記録"`）と**共有アイコン** 13px `--primary`（`aria-label="共有"`）。2 行目 12px `--muted-foreground` に「メモ · 方法」（メモが無ければ方法だけ）。
  - 右端に金額 16/600（符号付き）。
- **相手の立替は押せない**: 行全体を `div` にし、名前の後ろに「{名前}の立替」バッジ（h18 `padding 0 6px` r6 `--muted` 11/700）、2 行目の先頭に南京錠 11px。`aria-label="パートナーのみ編集できます"`（定期の記録一覧と同じ扱い）。
- 押せる行は**記録の編集モーダル**（T05 の `useNoteModal().open({ editing })`）を開く。原典は `RecordEdit.dc.html` へのリンクだが、実装では既存のモーダルに繋ぐ。

## 現状

- 画面も導線も無い（T12 で行は非リンク）。
- サーバは**揃っている**: `features/record` の `getSummarizedRecords(session, SummarizedRecordQuery)` が `isType` / `id` / `subTypeId` / `isIncludeInstead` を受け、`SummarizedRecordItem` に `plannedRecordId` / `isPair` / `pairUserName` / `isSelf` / `recordType` まで返す。デモ射影（`demo/server/queries/record.ts` の `getSummarizedRecords`）もある。**サーバ層の追加は不要**。

## やること

1. ルート `src/app/(private)/(tabs)/summary/records/page.tsx`。絞り込みは searchParams（`isType` / `id` / `subTypeId` / `isPay` / `isPair` / `instead` / `ym`）で受ける。
   **searchParams はクライアント値なので信用しない**: `isPair` はセッションとモードから、scope は `getSummarizedRecords` のリポジトリ側（`buildScopeWhere`）で担保される。`id` は scope 外なら空になる（IDOR は既存の作りで塞がっている）。
2. `features/summary/components/records-screen.tsx`（Client）。月移動は Server Action で取り直す（内訳と同じ `useTransition` で前の内容を残す）。
3. `features/summary/actions.ts` に `fetchSummarizedRecordsAction`（取得のみ）を足す。整形（日別グループ・日計・合計）は `domain/records-group.ts` の純関数にしてテストを付ける。
4. 見出しの名前・タグの文言組み立ては `domain/records-heading.ts`（テスト付き）。
5. T13 の一覧の親行・子行をこの画面へのリンクにする（精算行は非リンクのまま）。

## 完了条件

- デモ（ペアあり）で内訳の行をタップすると明細が開き、見出し・タグ 2 枚・合計が出る。
- 月を動かすと明細と合計が変わる。
- 自分の記録をタップすると記録の編集モーダルが開く。相手の立替は押せず、バッジと南京錠が出る。
- サブカテゴリの子行から開くと、そのサブカテゴリだけに絞られる。
- 0 件の月で空状態が出る。
