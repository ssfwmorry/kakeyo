## デザイン仕様

### 一覧
- ScreenHeader: 「‹ 設定」／空／**「並べ替え」⇄「完了」**。ScreenTitle「定期の記録」+ バッジ（モードに従う）。
- 説明 **「毎月決まった日に、自動で記録されます」**。
- サマリー 2 枚（grid 2 列 gap 8、白 r14 `padding 12 14`）: **「毎月の収入」** `+{合計}` 18/700 `--primary` ／ **「毎月の支出」** `−{合計}` 18/700 `--foreground`。合計は一覧の isPay 別の単純和（共有では立替・共有のお金を問わず全行）。
- 白カード r14。行 h64 px14 gap 12:
  - 先頭 w40 縦積み: **「毎月」** 10px `--muted-foreground` + `{D}日` 17/700。
  - 本文（先頭列の右にだけ上線）: 8px 色丸 + `{カテゴリ} › {サブ}`（サブ無しはカテゴリのみ）15 nowrap ／ 補足 12px `--muted-foreground` ellipsis: `[方法, (共有かつ支出なら 立替 ? 「自分が立替」 : 「共有のお金」), メモ]` を「 · 」で連結。**パートナーの立替行**（`isPair && pairUserName !== null && !isSelf`）: `{pairUserName}さんの立替 · {メモ}`。
  - 金額 16/600: 支出 `−{金額}` `--foreground` ／ 収入 `+{金額}` `--primary`。
  - 末尾: 通常シェブロン、並べ替え中はハンドル。編集可能行は button（`aria-label="毎月{D}日 {カテゴリ › サブ} を編集"`）→ 詳細シート（編集）。**パートナーの立替行は押せない div** で末尾に南京錠（`aria-label="パートナーのみ編集できます"`）。並べ替え中は行タップ無効。
  - 空: 「まだ定期の記録はありません」（カード内 h88）。
- 追加行「定期の記録を追加」（並べ替え中は非表示）→ カテゴリシート。
- 注記: 並べ替え中「ドラッグして並べ替えます。並び順は一覧の表示にだけ使われます。」／共有「パートナーが立て替える定期の記録は、パートナーだけが編集できます。共有／個人は登録後に切り替えられません。」／個人「行をタップすると編集・削除できます。」
- 行の並びは `sort` 順（日付でソートしない）。

### 追加 step1: カテゴリシート
- **全高固定**シート（内側スクロール可）、`padding 8 16 34`、gap 12。
- ヘッダー: 左 新規は ×「閉じる」／詳細から来たときは ‹「詳細に戻る」。中央 **「定期の記録を追加」**／詳細から来たときは **「カテゴリを変える」**。右 空。
- 「支出｜収入」セグメント `lg`。切替で展開・方法をクリア。
- ラベル「カテゴリ」+ 4 列グリッドと展開パネル（**T05 の入力①と同じ部品**を使う。「なしで進む」含む）。チップで詳細へ。サブカテゴリなしは即詳細へ。

### 追加 step2 / 編集: 詳細シート
- 全高固定、`padding 8 16 0`、gap 14、テンキーを下に張り付け。
- ヘッダー h48 grid `44px 1fr 44px`: 左 新規 ‹「カテゴリに戻る」／編集 ×「閉じる」。中央 白ピル（`aria-label="カテゴリを変える"`、10px 色丸 + `{カテゴリ › サブ}` 15/600 + 種別チップ「支出」（`--muted` 地）／「収入」（`--secondary`/`--primary`）+ 共有なら「共有」チップ。押すとカテゴリシート（`fromDetail`）。右 編集のみゴミ箱（`aria-label="この定期の記録を削除"`）。
- 白カード r14: 行 1 h52: Repeat アイコン + ラベル **「毎月」**（w34）+ セグメント（`role=group aria-label="毎月の記録日"`、`--background` 地）**「1日」「10日」「15日」「25日」**（`getDayClassifications` の value）。行 2 h52 `border-top --line-soft`: メモアイコン + 「メモ」+ `input aria-label="メモ" placeholder="任意（例：動画サブスク）"`。カード下 12px `--muted-foreground`: `次は {M}月{D}日 に自動で記録されます`（選んだ日が今日より後なら今月、そうでなければ翌月）。
- 共有かつ支出のみ: ラベル **「だれのお金で払う？」** + セグメント `xl`「自分が立替／あとで精算する」｜「共有のお金／精算しない」。切替で方法を先頭にリセット。
- ラベル 支出「支払方法」／収入「受取方法」+ 方法ピル（T05 と同じ）。候補が変わったとき選択が候補に無ければ先頭。
- 金額行（`mt-auto` h56）: 「クリア」+ `output aria-label="毎月の金額"` `−4,800`（支出 `--foreground`／収入 `--primary`）+「円」。テンキー（T05 の `Keypad`）。上限は `priceSchema` に従う。
- 保存バー: 新規 **「登録する」**／編集 **「変更を保存」**。無効（金額 0 またはカテゴリ未選択）「金額を入れると登録できます」。**共有でもメモ必須では無い**。
- 保存: 新規は追加、編集は差し替え、閉じてトースト「登録しました」／「変更しました」。

### 削除の確認
- `ConfirmAlert`（`aria-label="定期の記録を削除"`）: 「この定期の記録を削除しますか？」／「{カテゴリ › サブ}（毎月{D}日）は来月から記録されなくなります。これまでに記録された分は残ります。」／やめる｜削除。削除でシートも閉じ「削除しました」。
