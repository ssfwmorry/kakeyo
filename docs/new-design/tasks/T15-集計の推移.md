### カテゴリチップ（カテゴリ別のみ）

- 横スクロール（`margin 0 -16px; padding 0 16px` gap 6）。h32 r16 `padding 0 12px` 13px。
- 先頭は「全て」（ドット無し）。以降は各カテゴリ（8px の色ドット）。
- 選択中 = `--foreground` 地・白・600（ドットは白）、非選択 = `--card` 地・`--foreground`。

### グラフカード（白 r16 `padding 16px 16px 12px` gap 12）

- 見出し行: 左に「2026年の収支」13px `--muted-foreground` ＋ 値 26/700（負なら `--destructive`）＋「円」14/600。右に「9月の収支」12px ＋ 値 15/600。
- 棒グラフ 12 本（高さ 160px、`grid-template-columns: repeat(12, 1fr)`）:
  - **全体・収支**: 0 線をまたぐ。`posMax` と `negMax` から `scale = 150 / (posMax + negMax)`、0 線の位置 `zero = 5 + posMax * scale`。正は上向き r`4px 4px 0 0`・アクセント、負は下向き r`0 0 4px 4px`・`--destructive`。0 線は `--border` の 1px。
  - **全体・支出のみ** と **カテゴリ別**: 全て上向き。カテゴリ別は**積み上げ**（`flex-direction: column-reverse` で系列を下から積む）。
  - 棒の幅 14px（中央寄せ）。**月をタップで選択**でき、選択中は不透明度 1・地 `--fill-soft`・月ラベルが 700 `--foreground`、非選択は不透明度 .45・ラベル `--muted-foreground`。
  - `aria-label` は「9月 収支 +130,000円」のように読み上げる。
- 月ラベル行（12 列・10px、`margin-top: -6px`）。

### 凡例（カテゴリ別のみ）

グラフカードの中、`border-top 1px --line-soft` `padding-top 10px`。行 h32: 10px 角丸 3px の色四角 ／ 名前 14px（「サブカテゴリなし」は `--muted-foreground`）／ 選択月の値 12px `--muted-foreground` ／ 年間の値 14/600（幅 88 右寄せ）。
**積み上げの逆順**（上に積まれたものが先頭）で並べる。末尾に「{選択月}月」「年間」の見出し 11px。

### 月別テーブル（全体のみ）

## 完了メモ（2026-09-27）

- **サブカテゴリ名の穴を塞いだ**: `SubTypeSummaryRow` に `subTypeName` を足し、`services.getSubTypeSummary` とデモ射影で写すようにした。`buildSubTypeStack` は行の名前をそのまま使う（名前を引く関数の引数は不要になったので削除）。凡例に「食料品」「外食」の実名が出る。
- **系列の色を色名に変えた**: `StackSeries.color`（hex）→ `colorName`。描画時に `colorVar` で `--cat-*` に解決する。recharts 時代の hex 固定のままだとダークで色が追従しない（内訳のドーナツが既に色名で持っていたので、そちらに揃えた）。サブカテゴリの循環パレットも hex から色名（amber/green/deep-purple/pink/indigo/brown）に変えた。
- `domain/trend.ts`（テスト 10 件）: `buildSignedBars`（0 線をまたぐ棒。正負の最大で 150px を分け、0 は高さ 0・0 でない値は最低 2px）、`buildStackedBars`、`buildLegend`（積み上げの逆順）、`buildTrendTable`。見出しの対象名・符号の有無・年間合計の出どころは `TrendView` に寄せた（画面側の入れ子三項をなくすため）。
- 棒は div の高さだけで描く（SVG 不要）。描画領域 160px のうち値に使うのは 150px で、上下に 5px ずつ余白が残る（原典の `H = 150` と `top: 5 + …`）。
- **タブを共通部品にした**: `components/summary-tabs.tsx`。原典ではタブが別画面なので、選ぶと `/summary` `/summary/trend` へ `router.push` する。内訳側の `disabled` なセグメントは廃止。**精算タブはペアがいるときだけ出す**（T16 の前提。中身が無いので今は `disabled` のまま）。
- 年を移ると選択月は原典どおり（前の年へ → 12 月、次の年へ → 1 月）。初期の選択月は今月。
- 確認: デモ（ペアあり・個人）で 全体の収支（9 月 +138,220 がカレンダーと一致）、支出のみ（年計 1,039,280）、立替込み⇄自分のみ（9 月 111,780 ⇄ 108,780・内訳と一致）、月タップとテーブル行タップの連動、カテゴリ別の積み上げと凡例（9 月の住居 80,000 / 食費 15,280 が内訳と一致）、食費を選んでサブカテゴリ別（食料品 10,000 / 外食 5,280 が内訳の子行と一致）、年の移動（2025 年はデータが無く全て 0）。共有モードで収支が全月マイナスになり棒が下向きに出る（立替セグメントは出ない）。ペアなしデモでタブが 2 つになり立替セグメントも出ない。ダーク／ライト。`pnpm check:full` / `pnpm test`（283）/ `pnpm build` 通過。
