## デザイン仕様

### タブバー（浮くピル型・すりガラス）
- `position: fixed`（シェル幅内）`left 16 / right 16 / bottom max(26px, env(safe-area-inset-bottom))`、h64、`padding 8`、gap 4。
- `bg var(--bar)`、`backdrop-filter: blur(20px)`、`border 1px solid rgba(0,0,0,.06)`、r32、影 `0 10px 30px rgba(22,25,26,.14), 0 2px 6px rgba(22,25,26,.06)`（D17 の例外）。
- 5 スロット均等: カレンダー（lucide Calendar）／集計（PieChart）／＋／口座（**Landmark**）／設定（Settings）。アイコン 24 + ラベル 10px、gap 2。
- 選択中: h48 r24 `--line-soft` 地、`--primary`、ラベル 600。非選択: `--tab-muted`、ラベル 400、地なし。
- 中央＋: `aria-label="入力"`、48×48 の円、`--primary` 地、影 `0 4px 12px rgba(22,25,26,.22)`、Plus 22px 白 stroke 2.4。ラベルなし。押すと入力モーダル（T05）。本タスクでは見た目のみ直し、遷移は現状の `/v2/calendar?note=new` のままでよい。
- 本文はバーの下を通り抜ける。`(tabs)/layout.tsx` の `main` の下端 padding を `26 + 64 + 16` 相当（`calc(env(safe-area-inset-bottom) + 106px)`）にし、各画面の `pb-*` は外す。

### ヘッダー行（カレンダー・設定）
- 左: ベル 44×44 `margin-left -10px`、アイコン 22px stroke 2、`--foreground`。バッジ `top 7 right 7`、min-w16 h16 r8 `--destructive` 白 10/700。`aria-label="お知らせ（N件）"`。**押すとお知らせシート**を開く（リンクではない）。件数 0 でもベルは出す（バッジ無し）。
- 右: テーマ切替（40px 丸・アイコン 21px・ライト中は Moon「ダークモードに切り替え」、ダーク中は Sun「ライトモードに切り替え」）+ 個人｜共有（共通仕様）。

### お知らせシート（Notify）
- 内容高のボトムシート（共通仕様）。`role=dialog aria-label="お知らせ"`。縦 gap 14。
- ヘッダー: × ｜「お知らせ」17/600 + 件数バッジ（rows があるときのみ。h20 r10 `--destructive` 白 12/700）｜ 空。
- 説明 13px `--muted-foreground`: **「期日を過ぎたリマインダーです。済んだら「確認」を押すと、次の日付に進みます。」**
- 白カード r14。行 `padding 12px 14px`、縦 gap 8、2 行目以降 `border-top 1px var(--border)`:
  - 1 段目: 32px 色丸に頭文字 ／ 名前 16/600 ellipsis + 赤 12/600 `{M/D（曜）} が期日 · {N}日過ぎています` ／ 右に **「確認」** ボタン（h36 r18 `--primary` 白 14/700、チェックアイコン、`aria-label="{name}を確認して次の日付に進める"`）。
  - メモがあれば 13px（`padding-left 42`）。URL はリンクにする。
  - 補足 12px `--muted-foreground`（`padding-left 42`）: `確認すると {M/D（曜）} に次のお知らせ`。「予定に残す」型かつ「〜か月後」型なら `。この日の予定はカレンダーに残ります` を続ける（D16）。次回日付は `calcNextReminderDate`（`features/plan-reminder/domain/reminder-condition.ts`）で算出。
  - 空: h96 中央、チェックアイコン 24 + **「期日を過ぎたリマインダーはありません」** 14px `--muted-foreground`。
- 末尾リンク **「リマインダーの設定を開く ›」**（h44 中央、14/600 `--primary`）→ `/v2/setting/reminder`。
- 「確認」を押す: `checkReminderAction(reminderId)` → 成功で行を消し、件数バッジを減らす。トースト **`「{name}」を確認しました`**（成功）。0 件になれば空表示。
- 対象は `getReminderList(session).all` のうち `date < today`（D12）。並びは日付昇順。
