# T06 記録の編集（削除の確認・定期由来）

- 依存: T05。
- 原典: `project/RecordEdit.dc.html`（`confirm` = 削除の確認、`fromPlanned` = 定期由来）、`project/RecordEditDelete.dc.html`、`project/RecordEditPlanned.dc.html`。

## デザイン仕様
- 背面はカレンダー + 暗幕 `rgba(12,16,17,.42)`（`--overlay` で可）。シートは入力②と同じ**全高固定**（`top 56`、`--background`、gap 14）。入口は日別リストの記録行。
- ヘッダー h48 grid `44px 1fr 44px`: 左 × 36px 丸（`aria-label="閉じる"`）／中央 カテゴリピル（`aria-label="カテゴリを変える"`、押すと入力①へ。①では個人｜共有はロック表示）／右 **ゴミ箱** 36px 丸（`--muted` 地・`--destructive` アイコン、`aria-label="この記録を削除"`）。**個人｜共有セグメントは無い**（共有の記録はピルの「共有」タグで示す）。
- 日付＋メモカード: 入力②と同じ。前の日ボタンも上限で `--icon-muted`。
- **定期由来バナー**（`plannedRecordId` があるとき、カードの直下）: `margin-top -8`、`padding 8 12`、r10、`--secondary` 地、Repeat 16 `--primary`、本文 12px lh1.5 `--foreground` **「定期の記録から作られた記録です。日付は同じ月の中でだけ変えられます。」**。このとき前の日は元の記録の月の 1 日まで、次の日は今日まで。暦も同月に制限。
- 方法ラベルは **「支払方法」／「受取方法」**（「前回の…」は付けない）。ピルは入力②と同じ。
- 金額行・テンキーは入力②と同じ。
- 送信バー: **「保存する」**／不可時「金額を入れると保存できます」（金額 0）。共有記録のメモ必須は維持し「メモを入れると保存できます」（優先はメモ→金額）。
- 削除の確認（ConfirmAlert）: 「この記録を削除しますか？」／「{M月D日（曜）}の「{カテゴリ › サブ} {−|+}{金額}円」を削除します。削除すると元に戻せません。」／やめる｜削除。削除成功でシートを閉じ「削除しました」。
