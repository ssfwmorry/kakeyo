## デザイン仕様

### 提示方法（D1）
- 外枠は `#0C1011`（ほぼ黒）。その上に「縮んだ前の画面」のゴースト（`top 44 / left 10 / w 370 / h 800 / r14 / 地色 / opacity .5`）。その上に **全高固定シート**（`top 56px` から画面下端、`--background` 地、r20 上、`box-shadow 0 -8px 24px rgba(0,0,0,.18)`）。タブバーは覆われる。
- **どのタブからでも開き、閉じると元の画面へ**。実装: `src/app/v2/layout.tsx` に `NoteModalProvider`（Client Context: `open(initial?)` / `close()`）を置き、タブバーの＋・カレンダーの「記録」ボタンは `button` で `open()` を呼ぶ。候補データ（`getTypeCardList` / `getMethodCardList` / `getEffectivePairMode` / `hasPair` / `todayJst`）は v2 layout（Server Component）で取り、Provider に渡す。保存後は `revalidatePath('/v2', 'layout')` で開いた画面も更新される。`/v2/calendar?note=new` は廃止。
- 背面の縮小は `.v2-root` 内側のシェル div に `data-modal="open"` を付け `transform: scale(.95); border-radius: 14px; opacity: .5` を当てる（CSS のみ。無理なら暗幕 `--overlay` の濃いもので代替してよい）。
