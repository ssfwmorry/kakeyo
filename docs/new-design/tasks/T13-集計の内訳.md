## デザイン仕様

### タブ（内訳・推移・精算）

- セグメント: 外枠 `padding 3px` `--muted` r10、各 h32 r8 14px。選択 = `--card` 地 + `0 1px 3px rgba(0,0,0,.12)` 600、非選択 = 透明 `--muted-foreground`。
  T12 の `Segment`（`md`）と寸法が違うので、このタブ専用のサイズを `Segment` に足すか、集計側の部品にする。
- **3 つとも押せる**（T12 の `disabled` を外す）。精算はペアがいるときだけ出す（T16。ペア未設定なら 2 つ）。

### 月ナビ行

- 「前の月」「次の月」36px 丸は T12 のまま。
- 中央の月ラベルを**ボタンにする**（h36 `padding 0 6px` r8 透明地、16/600 ＋ 14px シェブロン下向き `--icon-muted`、`aria-label="表示する月を選ぶ"`）。押すと年月ピッカー。
- 右端の支出／収入ピルは T12 のまま。ただし**方法軸のときはラベルが「支払」「受取」に変わる**。

### 軸と立替の扱い（新しい行）

月ナビの下に 1 行（gap 8）:

- 左: セグメント `role="group" aria-label="集計の軸"`「カテゴリ」「方法」（h28 `padding 0 12px` r7、外枠 p2 `--muted` r9）。
- 右（`margin-left: auto`）: セグメント `aria-label="立替の扱い"`「立替込み」「自分のみ」。**共有モードでは出さない**（原典 `showInstead: !s.pair`）。

### ドーナツ

T12 のまま（中央ラベルは軸に連動して「支出合計／収入合計／支払合計／受取合計」）。

### 一覧の行

- 親行は T12 のまま。加えて:
  - **方法軸で立替の行は、名前の前に小さくユーザ名**（12px `--muted-foreground`）を出す（原典 `hasUser`/`user`。`pairUserName`）。
  - 共有の行は名前の後ろに**共有アイコン** 13px `--primary`（`aria-label="共有"`）。
  - **精算行は輪郭だけの丸**（`border: 2px solid` 黄・地は透明）で、バーの色は黄。非リンクでシェブロンの位置に 14px の空きを置く。
- **サブカテゴリの子行**（親の下に続ける）: h40 `padding 0 14px 0 36px`、本文は `border-top 1px --line-soft`（左端 36px から始まる）、名前 14px ＋ 割合 12px `--muted-foreground`、金額 14px、シェブロン。
  「サブカテゴリなし」は名前を `--muted-foreground` にする。**割合は全体に対する割合**（親比ではない。原典 `pctOf(u[1])` は total 基準）。

### 年月ピッカー（シート）

- 内容高のボトムシート。グラバー ／ ヘッダー（左 × 36px 丸・中央「表示する月」17/600・右は空） ／ 白カード r14 `padding 8px 12px 14px`:
  - 年の行 h44: 「前の年」「次の年」36px 丸（`--background` 地）＋ 中央「2026年」17/600。**2023 年より前へは行けない**（前の年ボタンの色を `--icon-muted` に落とし、押せなくする）。
  - 12 か月グリッド（4 列 gap 8）、各 h44 r12 15px。選択中 = `--primary` 地・白・700、他 = `--background` 地・`--foreground`。
  - 選ぶと**即座に**その月へ切り替えてシートを閉じる。
- 注記: 「選ぶとすぐにその月の内訳へ切り替わります。2023年より前は選べません。」

### 脚注

一覧の下に 12px `--muted-foreground` lh1.6 `padding 0 4px` で 1 行。モードで文言が変わる（`kind` は「支出／収入／支払／受取」）:

- 共有: 「共有モードは二人の家計を見るため、立替かどうかは区別せず、精算は含めません。」
- 個人・立替込み: 「立替込み：相手の分の立替と精算を含めた、相手を考慮した自分の{kind}です。」
- 個人・自分のみ: 「自分のみ：立替と精算を含めない、自分個人の{kind}です。」
